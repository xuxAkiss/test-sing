# 实验 002：《七里香》整首人声分离

## 目的

验证正式 `audio_engine separate` 命令能否处理完整 M4A 手机录音，并量化人声分离对音高检测的改善。

## 配置

- 输入：`myvoice/七里香.m4a`
- 时长：272.768 秒
- 模型：Demucs 4.1 `htdemucs`
- 设备：CPU
- shifts：0
- 分离耗时：95.616 秒

## 结果

| 指标 | 原始混录 | 分离人声 | 剩余伴奏 |
|---|---:|---:|---:|
| RMS | 0.05613 | 0.05085 | 0.02081 |
| 近静音比例 | 7.58% | 33.86% | 16.28% |
| 音高覆盖率 | 80.32% | 59.04% | 63.80% |
| 中位音高置信度 | 0.8834 | 0.9646 | 0.8400 |
| 音高边界命中率 | 1.86% | 1.49% | 3.39% |

## 结论

- 整首人声分离流程稳定运行，速度约为音频时长的 0.35 倍，CPU 足够支撑原型阶段的异步任务。
- 人声音高置信度显著提升，同时音高覆盖率和连续非静音比例下降，表明伴奏假音高被有效抑制。
- 分离人声的边界命中率较低，没有出现短片段前奏中大量贴近 700Hz 上限的异常。
- 下一阶段应加入标准旋律来源，才能从“提取用户音高”进入“判断用户唱得是否准确”。
